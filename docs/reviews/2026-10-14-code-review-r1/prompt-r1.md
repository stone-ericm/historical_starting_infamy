## What the boot does (so you know what "wasted" means)
The owner stages `research/probe/` as the only enabled mod, launches the game with `-debug_mode`, starts a New Game as France with the Infamy Generation rule set to Very Low, captures five war-goal infamy tooltips by hand (`research/measurement/capture-plan.md`), switches to observer, runs past 1836-04-01, quits, restores the playset. Then `tools/hsi/measurement.py extract` parses `debug.log`, the tooltips are transcribed into `research/fixtures.json`, and `tools/hsi/generate.py` produces the shipped effect from that single measurement, which then becomes immutable. If the probe does not load, does not fire, logs something the extractor cannot parse, logs the wrong quantities, or the five captures cannot pin the processing order the ordering registry needs, the boot is wasted and must be repeated. That is the most expensive failure here; the owner's time at the keyboard is the scarce resource.
